# Frontend Agent Rules

This app uses Next.js 16. Read relevant local docs in `node_modules/next/dist/docs/` before changing framework behavior such as Proxy, routing, Server Actions, caching, or config.

NearU has no platform payment system. Do not add wallet, checkout, payout, payment webhook, connected-account, or payment-required UI/backend behavior in the frontend.

Use the root `AGENTS.md`, `CLAUDE.md`, `structure.md`, and `backend_structure.md` for current project state.
